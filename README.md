## 📖 Sobre el proyecto

**Barrio Seguro** nace como respuesta a la necesidad de la Comisión Vecinal (integrada por 40 familias) de contar con una herramienta unificada para hacer frente a hechos de inseguridad. Este desarrollo se enmarca como un proyecto universitario desarrollado **Instituto Tecnológico Universitario (ITU)** para la materia programación de aplicaciones para celulares dictada por la docente Valeria Avellaneda.

El objetivo principal de esta aplicación es fortalecer la comunicación comunitaria, organizar esfuerzos de prevención (como el patrullaje vecinal) y proveer una vía rápida de alerta ante emergencias, operando bajo un modelo de red solidaria sin depender inicialmente de despachos policiales automatizados.

## ✨ Funcionalidades principales (MVP)

*   🚨 **Botón de Pánico (SOS):** Activación rápida con geolocalización en tiempo real que notifica instantáneamente a la red de vecinos.
*   📍 **Mapa de Alertas en Vivo:** Visualización interactiva de incidentes con filtros por estado (Activa, En atención, Resuelta).
*   📞 **Acceso Directo al 911:** Botón de un solo toque para enlazar la llamada con las fuerzas de seguridad públicas.
*   📅 **Módulo de Patrullaje:** Algoritmo de asignación de turnos para organizar las rondas vecinales según disponibilidad.
*   🔔 **Notificaciones Push:** Avisos segmentados por zona para mantener informados a los usuarios cercanos al incidente.
