## 📖 Sobre el Proyecto

**Barrio Seguro** nace como respuesta a la necesidad de la Comisión Vecinal (integrada por 40 familias) de contar con una herramienta unificada para hacer frente a hechos de inseguridad[cite: 1]. 

El objetivo principal de esta aplicación es fortalecer la comunicación comunitaria, organizar esfuerzos de prevención (como el patrullaje vecinal) y proveer una vía rápida de alerta ante emergencias, operando bajo un modelo de red solidaria sin depender inicialmente de despachos policiales automatizados[cite: 1].

## ✨ Funcionalidades Principales (MVP)

*   🚨 **Botón de Pánico (SOS):** Activación rápida con geolocalización en tiempo real que notifica instantáneamente a la red de vecinos[cite: 1].
*   📍 **Mapa de Alertas en Vivo:** Visualización interactiva de incidentes con filtros por estado (Activa, En atención, Resuelta)[cite: 1].
*   📞 **Acceso Directo al 911:** Botón de un solo toque para enlazar la llamada con las fuerzas de seguridad públicas[cite: 1].
*   📅 **Módulo de Patrullaje:** Algoritmo de asignación de turnos para organizar las rondas vecinales según disponibilidad[cite: 1].
*   🔔 **Notificaciones Push:** Avisos segmentados por zona para mantener informados a los usuarios cercanos al incidente[cite: 1].
